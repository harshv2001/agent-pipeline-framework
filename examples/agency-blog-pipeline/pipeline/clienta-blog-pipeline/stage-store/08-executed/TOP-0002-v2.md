## Why this item exists — the human-review revision loop, demonstrated

This is this pipeline's worked example of
`scripts/advance_stage.py --revise`: the Agent Reviewer passed the first
draft (`stage-store/07-rejected/TOP-0002.md`) as structurally complete,
but the human reviewer judged it too thin for a How-to post and asked
for more depth via `--revise` rather than `--approve` or `--reject`.
That is a real, recurring case this framework's design explicitly
accounts for (`docs/06-review-and-notification.md`, "Rejection is not a
dead end") — the human review gate is not assumed to only ever rubber-stamp
what the automated reviewer already passed.
